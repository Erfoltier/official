# チェックリスト（美容医療の広告）

主な根拠：医療法第6条の5〜、厚生労働省「医療広告ガイドライン」、医薬品医療機器等法（薬機法）、景品表示法（2023年10月施行のステルスマーケティング規制を含む）。
医療機関のWebサイトやSNSも、誘引性（患者を呼び込む意図）と特定性（医療機関名などが分かる）があれば「広告」として扱われる。

## 1. 禁止される広告（リスク：高）

| 種類 | 典型的なNG例 | 言い換えの方向性 |
|---|---|---|
| 虚偽広告 | 「絶対に失敗しない」「痛みゼロ」「必ず効果が出る」「1回で完全にシミが消える」 | 「痛みを抑える工夫として麻酔クリームを使用します」「効果には個人差があります」 |
| 比較優良広告 | 「日本一」「No.1」「地域最安」「他院より効果が高い」「最高の技術」 | 比較・最上級をやめ、事実（症例数＋集計期間、使用機器名など）を書く |
| 誇大広告 | 「〇〇の名医」「芸能人も通う」「最先端」「◯◯学会が認めた」（根拠のない権威付け） | 根拠のある事実のみ。経歴は客観的事実（卒業年・勤務歴など）で書く |
| 患者の体験談 | 「施術を受けた〇〇さんの声」「口コミ★5」「Googleレビュー転載」「患者さんから『若返った』と言われました」 | 削除する。体験談は内容が事実でも、治療効果に関するものは広告に使えない |
| ビフォーアフター写真（説明なし） | 写真だけ、または「たった1回でこの変化！」 | 写真の近くに、通常必要な**治療内容・費用・治療期間/回数・主なリスク・副作用**を詳しく併記する。それができないなら写真を外す |
| 公序良俗に反する | 過度に性的・差別的な表現、コンプレックスを過度にあおる表現 | 削除・全面修正 |
| 品位を損ねる | 「今だけ半額！」「先着10名様限定」「〇月中にお申込みで◯万円引き」など費用の過度な強調、「お友達紹介で◯円プレゼント」などの誘因 | 通常料金を明示する。期間限定・割引を前面に出す構成をやめる |
| 他院の誹謗 | 「他院で失敗した方へ」「安いクリニックは危険」 | 削除する |
| 広告できない専門医表示 | 厚労省に届け出のない団体の「専門医」「認定医」 | 広告可能な資格のみ表記する。不明なら要確認 |

## 2. 自由診療の「限定解除要件」（リスク：中〜高）

Webサイト・LPなどで、本来広告できない事項（詳しい治療内容・効果の説明など）を載せる場合は、次の**すべて**を分かりやすく併記する必要がある。
- 問い合わせ先（電話番号・メールなど）
- 自由診療であること、および**通常必要とされる治療内容・費用**（総額の目安、回数）
- **主なリスク・副作用**（ダウンタイム、内出血、色素沈着、感染、効果の個人差など）

チェックの観点：
- 「◯◯円〜」だけで総額の目安が分からない
- リスクの記載が「ほとんどありません」で終わっている
- リスクが別ページにしかなく、たどり着きにくい

## 3. 未承認医薬品・医療機器（リスク：高）

国内で未承認の薬剤・機器（海外製ボツリヌス製剤、一部のヒアルロン酸フィラー、輸入レーザー機器、適応外使用の内服薬など）を使う治療を広告する場合は、次をすべて明示する。
1. 未承認医薬品・医療機器であること
2. 入手経路（医師の個人輸入など）
3. 国内に同じ成分・性能の承認品があるかどうか
4. 諸外国での安全性などに関する情報
5. 医薬品副作用被害救済制度の対象外であること（医薬品の場合）

製剤名だけが書かれていて未承認かどうか判断できない場合は「要確認」とする。

## 4. SNS・インフルエンサー（リスク：高）

- クリニックが対価（無料施術、割引、金銭）を提供した投稿は**広告**。「PR」「広告」「#提供」などの表示がなければステマ規制（景品表示法）に違反する
- その投稿自体も医療広告ガイドラインの対象。インフルエンサー本人の体験談は「患者の体験談」に当たりやすい
- 医師・スタッフ個人のアカウントでも、クリニックへの誘導があれば広告として扱われる
- ハッシュタグもチェック対象（#最安値 #絶対小顔 #失敗しない など）

## 5. 薬機法（物販・ドクターズコスメ・サプリ）（リスク：中〜高）

- **化粧品**で効能として言えるのは、決められた56項目の範囲のみ。「シミが消える」「シワが治る」「肌の再生」「アンチエイジング効果」などはNG
  - OK例：「肌にうるおいを与える」「肌のキメを整える」「乾燥による小ジワを目立たなくする（効能評価試験済みの場合）」
- **医薬部外品**は承認された効能の範囲内のみ（例：「メラニンの生成を抑え、シミ・そばかすを防ぐ」）。「シミを消す」はNG
- **サプリ・健康食品**は疾病の治療・予防効果や身体機能の変化をうたえない（「飲む日焼け止め」「美白効果」など）
- 医師の推薦・監修を、効能を保証するように見せる表現（「医師が効果を保証」）はNG

## 6. その他の注意（リスク：低〜中）

- 「無料カウンセリング」自体は可。ただしキャンペーン色が強すぎる構成は「品位を損ねる」とみなされやすい
- 症例数・満足度などの数値は、根拠（集計期間・母数・調査方法）を併記する。根拠のない数値は誇大広告
- 「痛くない」「ダウンタイムなし」は断定を避け、「痛みの感じ方には個人差があります」「赤みが数日続くことがあります」などとする
- 医療脱毛・HIFUなどは、医療機関で行う施術であることと、エステとの違いを誇張しない

## 判断に迷うときの扱い

- ガイドラインの Q&A や自治体ごとの運用で判断が分かれる論点は、**断定せず「要確認」**とし、理由と安全側の言い換えを示す
- 最新の改正状況は、厚生労働省「医療広告ガイドライン」「医療広告ガイドラインに関するQ&A」の最新版で確認するよう案内する
