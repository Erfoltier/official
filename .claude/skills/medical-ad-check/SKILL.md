# 医療広告ガイドラインチェック

美容医療の広告文を、日本の医療広告ガイドラインを中心にチェックし、**違反の恐れがある箇所・理由・言い換え案**を返す。

## 手順

1. **対象を確認する**
   - 媒体（Instagram / X / TikTok / LP / 院内掲示 / メルマガ / ホットペッパー など）
   - 発信者（クリニック自身 / 医師個人 / 依頼したインフルエンサー / 物販用の化粧品ページ）
   - 対象が自由診療か、未承認医薬品・医療機器を使うか（分からなければ文面から推定し、推定であることを明記する）
2. **[references/rules.md](references/rules.md) のチェックリストを上から順に当てはめる**。文章だけでなく、ハッシュタグ、画像のキャプション、ビフォーアフター写真の有無、価格表記も対象にする
3. **指摘を表にまとめる**（出力形式は下記）
4. **修正版の全文を出す**。元の訴求力をできるだけ残し、必要な併記事項（治療内容・費用・リスク・副作用など）を補う
5. 判断が分かれるもの・情報不足のものは「要確認」として理由を書く

## 出力形式

```
## 判定サマリー
- 総合リスク：高 / 中 / 低
- 主な問題：（1〜3行）

## 指摘一覧
| # | 該当箇所（原文） | 問題の種類 | 根拠 | リスク | 言い換え案 |
|---|---|---|---|---|---|

## 不足している併記事項
- （限定解除要件・未承認医薬品の表示・PR表記などで足りないもの）

## 修正版（全文）
...

## 注意
本チェックはAIによる一次確認です。最終判断は所管の保健所・弁護士等にご確認ください。
```

リスクの目安：
- **高**：禁止事項に明確に当たる（体験談、条件を満たさないビフォーアフター、虚偽・誇大、比較優良、PR表記なしの依頼投稿など）
- **中**：書き方次第でアウトになる、または併記事項が足りない
- **低**：問題は小さいが、より安全な表現がある

## 原則

- **言い換えは「事実」と「条件」に寄せる**：効果の保証ではなく、治療内容・回数・期間・個人差・リスクを具体的に書く
- 指摘には必ず**理由**を書く（「NGです」だけで終わらせない）
- 法令やガイドラインは改正されることがある。自信がない論点は断定せず「要確認」とする
- ユーザーが「通る範囲で最大限訴求したい」と言っても、禁止事項をすり抜ける表現（体験談を「感想」と言い換えるなど）は提案しない
