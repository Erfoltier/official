# カウンセリング記録の要約

カウンセリングの書き起こしから、**カルテ下書き・患者さま向けサマリー・フォローメッセージ**を作る。作るのはあくまで**下書き**で、医師・スタッフが確認・修正してから使う前提とする。

## 最重要ルール

1. **書き起こしに無いことは書かない**。推測で補わない。読み取れない・聞き取れていない箇所は `【要確認：〜】` と書く
2. **医学的な判断を足さない**。診断名、施術の適否、薬の用量などは、医師が会話中に言ったものだけを記録する。AIの意見を書かない
3. **安全に関わる情報は必ず目立たせる**：アレルギー、服用中の薬（抗凝固薬、イソトレチノインなど）、妊娠・授乳、ケロイド体質、既往歴、過去の施術トラブル。会話に出てこなかった項目は「聴取なし」と書く（「なし」と書かない）
4. **患者さま向けの文章では売り込まない**：①と②は、説明された事実（内容・費用・リスク・ダウンタイム）を整理するだけにする。追加施術の勧誘、期限で急かす表現、効果の保証は書かない
5. 書き起こしは個人情報を含む。出力に、ユーザーが指定していない第三者の情報（同伴者の個人的な話など）を持ち込まない

## 手順

1. 書き起こしを読み、話者（医師 / カウンセラー / 患者）を区別する。話者ラベルがなければ文脈から推定し、推定であることを冒頭に1行書く
2. [references/formats.md](references/formats.md) の形式で ①カルテ下書き を作る
3. 同じ形式ファイルに沿って ②持ち帰りサマリー を作る（平易な言葉、中学生でも分かる程度）
4. ③フォローメッセージ を作る。送るタイミングはユーザーの指定に従い、指定がなければ施術当日夜・3日後・2週間後のうち会話内容に合うものを1つ選ぶ
5. 最後に `【要確認】` の一覧をまとめ、医師・スタッフがどこを直せばよいか分かるようにする

## 出力の構成

```
# ① カルテ下書き（医師・スタッフ用）
...
# ② 患者さま向け 持ち帰りサマリー
...
# ③ フォローメッセージ（送信タイミング：◯◯）
...
# 要確認リスト
- ...
```

患者さま向けの②③は、`medical-ad-check` スキルの基準（体験談の引用・効果の保証・費用の過度な強調をしない）にも沿わせる。
