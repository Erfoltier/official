# 出力フォーマット

## ① カルテ下書き（医師・スタッフ用）

簡潔な体言止めでよい。会話に出なかった項目は「聴取なし」と書く。

```
【日時・担当】（書き起こしから分かる範囲。不明なら【要確認】）

【主訴・ご希望】
- 例：両頬のシミが気になる。3か月後の結婚式までに目立たなくしたい

【⚠ 安全確認事項】
- アレルギー：
- 服用中の薬・サプリ：
- 妊娠・授乳：
- 既往歴・体質（ケロイド、ヘルペス、光線過敏など）：
- 過去の美容施術とトラブル：

【所見】（医師・スタッフが会話中に述べたものだけ）
- 例：医師「頬のシミは日光黒子が主体、一部に肝斑の可能性」

【提案した施術・治療】
| 施術名 | 回数・間隔 | 費用（税込） | 説明したダウンタイム・リスク |
|---|---|---|---|

【患者さまの反応・決定事項】
- 例：ピコスポットは本日予約。肝斑の内服は次回検討

【説明・同意の記録】
- リスク・副作用の説明：済 / 一部 / 聴取なし
- 費用総額の説明：済 / 一部 / 聴取なし
- 同意書：取得済 / 未 / 不明

【次回予定・宿題】
- 例：2週間後に経過確認。それまで日焼け止めを毎日使用

【要確認】
- 例：「先月どこかで何か打った」の詳細（施術名・施術部位）
```

## ② 患者さま向け 持ち帰りサマリー

やさしい言葉で、A4 1枚程度。専門用語には一言説明を付ける。

```
〇〇様　本日のカウンセリング内容

■ ご相談いただいたこと
・

■ 医師・スタッフからのご説明
・（所見を平易に。例：「頬のシミは主に紫外線によるもので、一部に肝斑（かんぱん：ホルモンなどが関係するシミ）の可能性があります」）

■ ご提案した治療
・施術名／回数の目安／費用の目安（総額）
・ダウンタイム：（例：施術部位にかさぶたができ、1〜2週間ではがれます）
・主なリスク・副作用：（例：色素沈着が一時的に濃くなることがあります）
・効果には個人差があります

■ 本日お決めいただいたこと
・

■ ご自宅で気をつけていただくこと
・

■ 次回のご予定
・

ご不明な点や気になる症状があれば、いつでも〇〇クリニック（電話：【要確認】）までご連絡ください。
```

## ③ フォローメッセージ（LINE・メール）

- 150〜250文字程度。絵文字は控えめ（0〜1個）
- 目的は**経過確認と安心**。次の施術の勧誘、キャンペーンの案内は入れない
- 受診を勧めるべき症状を具体的に書く（強い腫れ・痛み、水ぶくれ、膿、発熱など、説明されたリスクに合わせる）
- 患者さまが返信しやすい質問で終える

例（ピコスポット施術3日後）：
```
〇〇様
先日はご来院ありがとうございました。〇〇クリニックの△△です。
施術から3日たちましたが、お肌の様子はいかがでしょうか。
かさぶたは1〜2週間で自然にはがれますので、無理にはがさず、日焼け止めでのケアを続けてください。
もし強い痛みや腫れ、水ぶくれが出た場合は、お早めにご連絡ください。
気になることがあれば、このメッセージにそのままご返信くださいね。
```

## 要確認リスト

- 書き起こしの聞き取れない箇所、話者が曖昧な箇所、数字（費用・回数）の食い違い、安全確認事項の「聴取なし」項目をまとめる
- それぞれ「どこを・誰に確認すればよいか」を1行で書く
