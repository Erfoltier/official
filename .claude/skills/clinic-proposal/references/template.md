# 提案資料テンプレート

各章の見出しはこのまま使い、中身を埋める。サービスに関係しない章は「該当なし」とせず、丸ごと省く。

---

## 0. 表紙
- タイトル：「〇〇クリニック様　〔サービス名〕のご提案」
- サブタイトル：一言で効果を表す（例：「術後フォローを自動化し、スタッフの電話対応と患者さまの不安を減らす」）
- 提出日・提案者名

## 1. エグゼクティブサマリー（1ページ）
- **ご提案**：何を導入するか（1〜2文）
- **期待できる効果**：数字で2〜3点（保守的な試算）
- **費用**：初期費用・月額
- **次のステップ**：例「1か月の無償試験導入（患者さま30名）」

## 2. 現状の課題
- 現場で起きていることを3つまで（例：術後の問い合わせ電話、カウンセリング後の失注、SNS運用の手間）
- 可能ならクリニックの数字、なければ業界一般の傾向＋【仮定】

## 3. ご提案内容
- サービスの概要（誰が・いつ・何をするか）
- **導入後の1日の流れ**（患者さま側とスタッフ側をそれぞれ短く）
- 画面イメージや流れ図（あれば）

## 4. 期待できる効果（試算）
| 項目 | 計算式 | 保守的 | 標準 |
|---|---|---|---|
| 例：電話対応の削減 | 月件数 × 削減率 × 1件あたり時間 × 時給 | | |
| 例：リピート率の向上 | 対象患者数 × 向上幅 × 平均単価 | | |

- 前提条件を箇条書きで明記し、【仮定】の数字を差し替えられるようにする

## 5. 費用
- 初期費用 / 月額 / オプション
- **投資回収の目安**：月額費用 ÷ 月の効果額

## 6. 導入ステップ
| 時期 | 内容 | クリニック側の作業 |
|---|---|---|
| 1週目 | 初期設定・スタッフ説明会（30分） | 担当者1名のアサイン |
| 2〜5週目 | 試験導入（対象を限定） | 患者さまへのご案内 |
| 6週目 | 効果測定・本導入の判断 | 振り返りミーティング |

- クリニックの手間が少ないことを具体的に示す

## 7. 法令・安全面への配慮
サービスに関係するものだけ書く。
- **医療行為との線引き**：AIは診断・治療判断をせず、記録・連絡・振り分けの補助にとどめる。最終判断は医師
- **個人情報**：肌写真・病歴は要配慮個人情報。取得時の同意、保存場所、アクセス権限、削除方法
- **医療広告ガイドライン**：患者さま向けの文面・SNS投稿が体験談・誇大表現にならないようにチェックする仕組み
- **オンライン診療の指針**：診療行為を含む場合のみ
- トラブル時の対応（AIの誤判定時に医師へ回す流れなど）

## 8. よくあるご質問
- 「スタッフがITに不慣れでも使えるか」「既存の予約システム・電子カルテと連携できるか」「解約はいつでもできるか」など、院長が気にしそうな質問を3〜5個

## 9. 次のアクション
- 具体的な依頼を1つだけ書く（例：「◯月◯日までに試験導入のご判断をいただけますと、◯月から開始できます」）
- 連絡先
