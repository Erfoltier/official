美容皮膚科の受付・看護師・医師・院長が使う予約管理アプリ 「LANE RESERVE（レーンリザーブ）」 の使い方です。ブラウザのタブの題名・ホーム画面に追加したときの名前とアイコンも「LANE RESERVE」です。 はじめて触るスタッフが、この1冊で毎日の仕事をできるように書いています。

画面の写真について 写真はすべて、開発用の 架空のデモデータ（デモ皮フ科・架空の患者）で撮ったものです。実在の患者は写っていません。 撮影日は 2026年10月9日（金）と 10月14日（水）の画面です。院ごとの設定（配色・レーン名・メニュー）によって、見た目は少し変わります。 受付箱の申請（架空 花子・架空 太郎・見本 さくら）、リマインドの送り先に使ったメールアドレス（example.com）も、マニュアル用に作った架空のものです。

未確認 と書いてある所は、コードには機能があるものの、デモ環境では画面で動きを確かめられなかった所です（実際に LINE・メールを送る操作、Airリザーブにログインする操作、Googleドライブとつなぐ操作）。本番で使う前に確かめてください。

1. はじめに

このアプリでできること

  • 1日の予約を、レーン（列）ごと・時間ごとに1画面で見る
  • 空いている所を押して予約を入れる。ドラッグで時間やレーンを変える
  • 来院・待ち・施術中・会計待ち・帰宅などの 状態 を付けて、院内で進み具合を共有する
  • 患者の基本情報・注意事項・施術歴（簡易カルテ）・問診票・同意書・見積書を1か所で見る
  • だれが何を変えたかを記録する（患者情報の中身は記録に残しません）

パソコン・タブレット・スマホのブラウザで使います。ほかの端末で変えた内容は 20秒ごと と、画面に戻ったときに自動で読み直されます。

用語

管理操作 設定の変更や患者の削除・統合などの操作。院長・管理者と受付ができ、院長がほかのスタッフに許可することもできます（15章）

2. ログイン

院の入口でパスワード（Basic認証）を聞かれる場合は、院で決めたものを入れます（設定されていなければ聞かれません）。そのあと、スタッフごとにログインします。

ログイン画面の上には LANE RESERVE のロゴ（赤枠）が出て、ブラウザのタブの題名は「ログイン｜LANE RESERVE」になります。

  1. 一覧から 自分の名前（①）を押します。
  2. 数字のボタンで PIN を入れます（①）。間違えたら「⌫」で1文字消します。
  3. OK（②）を押すと予約表が開きます。
  • ログインは 12時間 有効です。過ぎるともう一度ログインします。
  • スタッフを交代するときは、予約表の右上の 「名前 ⇄」 を押し、確認で OK を押すとログイン画面に戻ります。
  • PIN を 5回続けて間違えると5分間ログインできません。さらに間違えると、ロックの時間が倍々に長くなります（最長24時間）。
  • デモ環境のPINは全員 1234 です。本番では院長が設定画面で各スタッフのPINを決めます（新しく決めるPINは 6〜8桁の数字）。

  • 「全体表示」を押したところ。

3-2. 予約枠の印

印 意味
C：赤い「!」 患者に 注意事項 がある（アレルギー・禁忌など）。必ず患者情報を確認してください
L：LINE 患者のLINEが紐付いている
S：1/2・2/3 など 同じ日に同じ患者の枠が複数あるとき、何番目の枠か（例：撮影→説明→施術）
T：右上の赤い三角 同じレーンで時間が 重なっている 予約がある。2人同時の施術でなければ、どちらかを動かしてください
P：右端の色の札 今の 状態（来院済・処置中・帰宅など）と、その状態にした時刻
  • 枠の色はメニューの色です。キャンセル・無断キャンセルの枠は通常は表示されません。
  • 枠に出す情報（名前・時刻・施術）は、設定 → 画面の表示・配色 で端末ごとに選べます。

3-3. 日付を選ぶ

日付のボタンを押すとカレンダーが開きます。日付の下の小さな数字はその日の予約数、赤い字は祝日です。「1週前／1週後／2週後／4週後」で次回予約の日へすぐ移れます。

3-4. Todaysメモ

  1. 予約表の一番上、レーンの下の欄（何も書いていないときは「＋」）を押します。
  2. 担当スタッフ・今日の注意点などを書きます（最大1000文字）。
  3. 枠の外を押すか Ctrl＋Enter で保存します。Esc で取り消し。

3-5. 受付一覧

左側の一覧には、その日の患者が時刻順に並びます（右上はレーンの絞り込み、「«」でたたむ）。パソコンでは最初から開き、スマホ・タブレットではたたまれています。

  • 行を押すと、予約表のその予約が選ばれ、右に詳細が出ます。
  • 行の左下の 状態の札（予約・帰宅など） を押すと、状態を選ぶ窓が開き、その場で状態を変えられます（6章）。
  • 「受付メモ」を押すと、その日の受付メモを書けます。

3-6. 氏名を伏せる

患者から画面が見える場所では 「氏名を伏せる」 を押します。姓の1文字以外が「＊」になり、詳細パネルの電話番号なども隠れます。もう一度押すと戻ります（この設定は端末ごと）。

4. 予約を入れる

4-1. 基本の手順

  1. 予約表で、入れたいレーン・時刻の 空いている所を押します（①）。5分刻みで、押した時刻が開始になります。
    ※右に詳細パネルが開いているときは、1回目の押しで詳細が閉じます。もう一度押してください。
  2. 「新しい予約」の画面が開きます。
  3. 患者 の欄に、氏名・フリガナ・ローマ字・診察券／M3番号・電話・予約申請ID のどれかを入れます（②）。候補が出たら押して選びます。
    ひらがな／カタカナ、全角／半角、大文字／小文字、空白の違いは気にしなくて大丈夫です。
  4. メニュー を選びます。上の欄（③）に「脱毛」「ボトックス」などを入れると絞り込めます。押すと追加され、複数選べます（× で外す）。
    そのレーンで通常行わないメニューは、薄く・後ろに表示されます。
  5. 開始・時間・レーン を確かめます（④）。時間はメニューの初期値が自動で入ります（複数なら合計）。
  6. 必要なら メモ と 予約申請ID（LINE予約フォーム） を入れます。
  7. 下の 「○:○○–○:○○ で登録」（⑤）を押します。
  8. 「予約を登録しました」と出て、登録した予約が選ばれた状態になります。

4-2. 出てくる警告

赤い枠（W）の警告が出ても登録はできます。内容を確かめてから登録してください。

  • 「『○○』は通常 1番・3番 で行います」… そのレーンで通常行わないメニュー
  • 「メニューの設定（10〜60分）の範囲外です」「メニューの設定は○分（固定）です」… メニューを1つだけ選んだとき、時間が設定と合わない

次のときは 登録できません（赤字で理由が出ます）。

  • 患者を選んでいない／メニューを選んでいない
  • 診療時間を超えている
  • 予約申請IDに英数字・ハイフン以外が入っている

同じレーン・同じ時間に別の予約があっても登録できます（右上に赤い三角が付きます）。

4-3. 新しい患者を登録しながら予約する

  1. 患者の欄の下の 「＋新規患者登録」 を押します（検索欄の文字は氏名に入ります）。
  2. 氏名（必須）・フリガナ・別の表記（ローマ字・旧姓など）・電話・生年月日・M3カルテ番号を入れます。氏名は 漢字・ひらがな・カタカナ・ローマ字を混ぜて 入れられます（例：山田 Anna、LEE Min-ji）。
  3. 診察券番号は自動で振られます。メニュー・時間を選んで登録すると、患者も同時に登録されます。
  4. 既存の患者から選び直すときは「← 既存の患者から探す」。

4-4. LINE予約申請の文面から入れる

  1. 「📋 LINE予約申請を貼り付けて入力」を押します。
  2. 申請の文面（「漢字氏名：…」「電話番号：…」「予約申請ID：…」の形）を貼り付け、「読み取って入力」を押します。
  3. 同じ電話番号で氏名かフリガナも合う患者が1人いればその患者が選ばれます。いなければ新規患者の欄に入ります。希望日がこの日と違うときは知らせが出ます。
  4. 内容を確かめて登録します。

受付箱から入れる：上のバーの 📥（受付箱） を押すと、最近30日のLINE予約申請のうち希望日が今日以降のものが新しい順に並びます。未対応の申請があると、📥 に件数の赤い札が付きます。各申請には、氏名・フリガナ・初診／再診・希望日と時間帯・内容・相談・生年月日・電話・申請の日時と予約申請IDが出ます（申込者の LINE の ID は出ません）。

  1. 申請の 「予約を作る（希望日）」（①）を押します。
  2. 希望日の予約表に切り替わり、申請の文面を読み取った「新しい予約」の画面が開きます。同じ患者が見つからないときは「新しい患者として入力しました。内容を確かめて登録してください」と出て（①）、氏名・フリガナ・電話・生年月日が新規患者の欄に入ります（②）。同じ電話番号で氏名かフリガナも合う患者が1人いれば、その患者が選ばれます。
  3. 時刻は診療開始の時刻・先頭のレーンで開くので、メニュー・開始・時間・レーンを選び直します。メモには申請の内容（希望日・受診区分・希望・相談など）が、予約申請ID（③）には申請IDが入っています。確かめて登録（④）します。
  4. 登録した申請は受付箱で「予約済み」になり、未対応の一覧から消えます（Airリザーブから取り込んだ予約のメモに申請IDがある場合も「予約済み」）。メモに申請IDがなくても、カナ（または氏名）と電話（または生年月日）の両方が合う予約が申請日以降にあれば「予約済み（推定）」になります。
  5. 電話などで対応した申請は 「済み」、受けない申請は 「見送り」 にします。「未対応に戻す」で戻せます。「予約済み・済み・見送りも表示」にチェックを入れると、対応済みの申請も見られます。

写真の申請は、マニュアル用に作った架空の申請です。

申請の LINE を確かめる・患者に紐付ける

予約申請IDが入った予約の詳細では、名前の行に 「申請 R…」（①）が出ます。申請IDの申込者の LINE が見つかり、申請の氏名・フリガナ・電話のどれか、または生年月日が患者と合うとき（生年月日が両方に入っていて違うときは不一致）は 「LINE（申込者）」（②）と出て、リマインドはその LINE に届きます。患者にまだ LINE が紐付いていなければ 「＋患者に紐付け」（③）も出ます。

  • 申請IDの申請が見つからないときは赤い字で「LINE 不明」、名前・生年月日が合わないときは「⚠ 申請と患者が不一致」と出ます。このときは LINE では送りません。申請IDを確かめてください。
  • 名前の行に入りきらないときは、「LINE（申込者）」や「＋患者に紐付け」が次の行に折り返して出ます。

「＋患者に紐付け」を押すと、「申請の名前・生年月日が『○○』さんと合っています。この LINE を患者に紐付けますか？」とブラウザの確認が出ます。OK（①）で紐付け（「LINE を紐付けました」と出ます）、キャンセル（②）でやめます。紐付けると、電話・窓口で取った予約にも LINE でリマインドが届くようになります。家族が代わりに申し込んだ場合は、紐付けないでください。（この写真は、ブラウザの枠ごと撮っています）

4-5. メニューがないとき

院長・管理者・受付は、メニュー一覧の下の「⚙ メニューの追加・削除」から、その場でメニューを作れます。作ったメニューはこの予約に入ります。

5. 予約を動かす・長さを変える

5-1. ドラッグで動かす（時間・レーン）

  1. 予約枠を押したまま、動かしたい時刻・レーンへずらします（5分刻み）。点線の枠が移動先です。
    スマホ・タブレットでは 長押し してから動かします（選択中の予約はすぐ動かせます）。
  2. 指（マウス）を離すと 「予約時間を移動してよろしいですか？」 と出ます。変更前→変更後の時間・レーンを確かめます。
  3. はい で保存、キャンセル で元に戻ります。

5-2. 長さを変える

  1. 予約枠を押して選びます。
  2. 枠の下端に出る つまみ（①）を上下にドラッグします（5分刻み）。
  3. 同じように確認が出るので はい を押します。

5-3. 別の日へ移す・メニューを変える（予約を変更）

ドラッグでは同じ日の中しか動かせません。別の日にする・メニューを変えるときは、詳細パネルの 「🗓 予約を変更」 を使います。

  1. 予約を押して右の詳細を開き、「🗓 予約を変更」を押します。
  2. 日付・開始・時間・レーンを選びます。「1週前／1週後／2週後／4週後」で日付をすぐ変えられます。
  3. メニューは × で外し、下の一覧から追加します。
  4. 下の「→ …」に変更後の内容が出るので確かめ、変更する を押します。別の日に移したときは、その日の予約表に切り替わります。

6. 来院から会計までの状態の付け方

6-1. 予約の詳細パネル

予約枠を押すと、パソコンでは右に、スマホでは下から 詳細 が出ます。

番号 できること
① 👤 患者情報の表示/編集（患者画面を重ねて開く）
② 🗓 予約を変更（5-3）
③ 🩺 カルテ・📄 同意書・📝 見積/会計（10章）
④ 状態のボタン
⑤ キャンセル／無断キャンセル（7章）

ほかに、日時・レーン・施術・担当記録（登録した人・最後に変えた人）・リマインドの状態、その日の写真・ファイル（📷 撮影／📎 ファイル）、連絡（電話番号を押すと電話をかけられる端末ではそのまま発信）、予約メモがあります。名前の横の「＋注意事項」で注意事項をその場で書き足せます。「＋申請ID」で予約申請IDを入れ直せます（4-4）。

リマインドの状態（①）には「未送信」「送信済み（前日・LINE など）」「送信しない」「送信失敗」と、送れなかったときは理由が出ます（例：「送信しない（送り先なし）」＝LINE のつながりもメールアドレスもない、「（不要の患者）」＝リマインド不要の患者、「（LINE の残り通数が少ない）」「（申請の名前・生年月日が患者と合わない）」など）。送り先は 設定 →「リマインド」の 送り先の確認 で、送らずに前もって確かめられます（13章）。

「今すぐ送る」を押すと「この来院へ、いまリマインドを送ります。よろしいですか？」と出て、OK でその来院へ1通送ります（リマインド不要の患者にも送ります）。送れないときは理由が出ます（例：「送り先がありません：申請IDの欄にもメモにも予約申請IDがなく、LINE の紐付けもない／患者のメールアドレスがない」）。キャンセル・承認待ちの予約には送れません。未確認 実際に送る操作は、デモでは押していません。

6-2. 状態を付ける

初期の流れの例：予約 → 来院済 → （医師待ち・看護師待ち・撮影待ち・麻酔待ち・待機中・検討中）→ 診察中／処置中 → 会計待ち → 帰宅

  1. 患者が来たら、詳細パネルの 「来院済」 を押します。押したボタンが色付きになり、押した時刻が付きます。予約枠の右端にも札が出ます。
  2. 待ち・診察・処置・会計待ちと進むたびに、そのボタンを押します。
  3. 会計が終わって帰ったら 「帰宅」 を押します。

ポイント：

  • 同じ日に同じ患者の枠が複数あるときは、全部の枠の状態がそろって変わります（キャンセル系は押した枠だけ）。
  • 押し忘れたときは、「時刻」欄に実際の時刻を入れてから状態のボタンを押すと、その時刻で記録されます。状態はそのままで時刻だけ直すときは、時刻を入れて 「時刻だけ直す」 を押します（空欄なら押した時刻）。
  • 左の受付一覧の状態の札からも同じように変えられます（3-5）。
  • 状態の名前・色・数は院で変えられます（13章）。

6-3. 自由入力（ひとこと）

「＋自由入力」を押すと、状態とは別に短い一言（20文字まで。例：15時までに出たい）を付けられます。「決定」で保存、「消す」で消します。予約枠にも札で表示されます。

7. キャンセル

7-1. キャンセル・無断キャンセルにする

  1. 予約枠を押して詳細を開きます。
  2. 下の 「キャンセル」 または 「無断キャンセル」 を押します。
  3. 「○○さんの予約をキャンセルにします。よろしいですか？」と出ます。はい（①）で確定、いいえ（②）でやめます。誤タッチ防止のため、必ずこの確認が出ます。
  4. 確定すると、予約表から枠が消えます（詳細にはキャンセルの札が付きます）。

管理操作のできる人は、「🗓 予約を変更」の画面の左下 「予約を取り消す」→「はい、取り消す」 でも取り消せます。

7-2. キャンセルした予約を見る

上のバーの 「キャンセル表示」 を押すと、取り消した予約が斜線入りで薄く表示されます。

7-3. 取り消した予約を「予約」に戻す

間違えてキャンセル・無断キャンセルにしたときは、入れ直さずに元へ戻せます。

  1. 上のバーの 「キャンセル表示」 を押して、取り消した予約を表示します。
  2. 取り消した予約の枠（①）を押すと、右に詳細が開きます。上に「この予約はキャンセルになっています。」と出ます（取り消した予約はドラッグでは動かせません）。
  3. 「予約に戻す」（②）を押します。
  4. 「この予約を『予約』に戻します。よろしいですか？」とブラウザの確認が出るので、OK（①）を押します。やめるときは キャンセル（②）。ボタンの見た目と名前はブラウザによって少し違います（この写真は、ブラウザの枠ごと撮っています）。
  5. 予約は「予約」の状態に戻り、予約表に普通の枠で表示されます。同じ時間に別の予約が入っていれば、右上に赤い三角が付きます。

8. 患者を探す・登録する・編集する

8-1. 患者を探す

  1. 予約表の右上の 👤 を押します。
  2. 検索欄（①）に、氏名・フリガナ・ローマ字・診察券／M3番号・電話・予約申請ID のどれかを入れます。何も入れていないときは「最近登録・更新した患者」が出ます。
  3. 半角カナでもひらがなでも探せます（例：「ﾔﾏﾀﾞ」で山田さんが出ます）。名前を押すと患者画面が開きます。

予約の詳細の「👤 患者情報の表示/編集」からも、同じ患者画面を開けます。

8-2. 患者を登録する（予約なしで）

  1. 患者一覧の 「＋新規登録」（②）を押します。
  2. 氏名（必須）・フリガナ・生年月日・電話番号を入れて 「登録する」 を押すと、その患者の画面が開きます。住所・注意事項などはそこで入れます。

8-3. 患者画面の見方

上から順に：

  1. 名前・フリガナ・年齢・診察券番号・電話・LINEの印。名前の横の「＋注意事項」で注意事項を書き足せます。
  2. 重複や削除のお知らせ（あるときだけ）
  3. 基本情報の表示/編集（①、押すと開く）
  4. 施術歴（②）：今回の予約／過去の履歴／今後の予約
  5. 同意書・見積・会計の控え
  6. その他の操作（写真比較・重複している患者をまとめる・この患者を削除）
  7. 変更履歴

8-4. 基本情報を直す

  1. 「基本情報の表示/編集」を押して開きます。
  2. 氏名・フリガナ・別の表記・診察券番号・M3カルテ番号・生年月日（年齢が自動で出ます）・性別を直します。変えた欄は色が付きます（①）。
  3. 連絡先情報（②）は、押すと開きます（電話・メール・リマインドの送り先・リマインド不要・郵便番号・住所）。閉じているときも、見出しの横に電話番号と「住所あり」が出ます。
  4. 下へ進むと 注意事項・既往歴・メモ があります。 - 「注意事項あり」にチェックすると、予約表に「!」が出ます。 - 重要事項（アルコール綿禁止・薬疹・アレルギー・禁忌など）はカルテの上に目立つように出ます。 - 既往歴・内服歴・その他の問診票情報（問診票が届くたびに日付付きで足されます）・院内メモ。 - 問診票の回答があれば、最新の既往歴・内服歴・アレルギーが表示され、「この問診票の回答をすべて見る」で全部の回答を見られます（9章）。
  5. 一番下の「○項目を変更中」を確かめ、保存（③）を押します。やめるときは「元に戻す」。

LINE欄の「紐付けを解除」で、LINEの紐付けを外せます（確認が出ます）。

8-5. 施術歴（簡易カルテ）・今後の予約

  • 今回の予約：今日の予約（なければ次回の予約日）。
  • 過去の履歴：日付ごとに、施術内容（〈○回目〉付き）・メモ・スキンケア＆内服が並びます。各行の「📝 メモ」「🩺 カルテ」「📷 撮影」「📎 ファイル」で記録を足せます。「＋ 予約のない日の記録を追加」で、予約のない日の記録も作れます。たくさんあるときは「さらに表示」。
  • 今後の予約：日付・時間・メニュー・レーン・状態・予約メモ。「変更」でその予約を直せます。

8-6. 変更履歴

画面の一番下に、「いつ・だれが・どの項目を」変えたかが出ます（値そのものは残しません）。問診票から自動で入った分は「問診票（自動取り込み）」と出ます。

8-7. 重複している患者をまとめる（統合）

氏名・フリガナ・電話番号・M3カルテ番号のどれか が同じ患者がいると、患者画面の上に 「同じ人が重複して登録されているかもしれません」 と出ます（お知らせが出るだけで、まだ統合はされません）。実際に統合できるのは、姓名・フリガナ（セイメイ）・生年月日がすべて一致する場合だけ です（院長・管理者と受付）。生年月日が両方とも未入力なら、姓名とフリガナが一致すれば統合できます。どれかが食い違うときは「統合不可」と理由が出ます。

  1. 「確認して統合」（または「その他の操作」→「重複している患者をまとめる」で相手を探す）を押します。
  2. 残す方 を選びます。もう一方の予約・施術歴・記録は残す方へ移り、空欄は補われ、注意事項・院内メモはつなげられます。
  3. 内容を確かめて 統合する を押します。
  4. 残した方に「統合しました」と出ます。
  5. まとめた側は削除扱いで残り、「統合先の患者を開く」リンクと 「統合を取り消す」 ボタンが出ます。

8-8. 患者を削除する・元に戻す

診療の記録は残す必要があるため、本当には消さず「削除済み」にします（院長・管理者と受付）。今日以降の予約がある患者は削除できません。

  1. 患者画面の「その他の操作」→ 「この患者を削除」 を押します。
  2. 理由（誤って登録した／重複して登録した／本人の希望／その他）を選び、削除する を押します。
  3. 削除した患者は検索・一覧に出なくなります。画面の上に「この患者は削除されています」と出て、「削除を取り消して復元する」（①）で元に戻せます。

8-9. ほかの人が同時に同じ患者を直したとき

2台で同じ患者を直し、先にほかの端末が保存していると、後から保存した側に 「他の端末でこの患者の情報が先に更新されました。最新の内容を読み込む（入力中の変更は消えます）」 と出て、上書きされません。入力した内容を控えてから「最新の内容を読み込む」を押し、もう一度直してください。

9. 問診票

Googleフォームの問診票の回答は、自動でこのアプリに送られます（院で送る仕組みの設置が必要です）。

9-1. 回答が患者に結びつく決まり

  • 氏名（またはフリガナ）＋生年月日か電話番号 が合う患者が1人いれば、自動で結びつきます。
  • 結びついた回答は、患者画面の「注意事項・既往歴・メモ」（8-4）と、カルテの「既往歴・内服歴」で見られます。電話・メールアドレス・住所・既往歴などの空いている欄にも写され、変更履歴に「問診票（自動取り込み）」と残ります（メールアドレスは患者のメール欄が空のときだけ写します。リマインドのメールの送り先になります）。

9-2. 結びつかなかった回答を結びつける

合う患者がいない・2人以上いる回答は、設定 → 問診票 に一覧で出ます。

  1. 予約表の ⚙ → 「問診票」タブを開きます。
  2. 回答日時・氏名・生年月日・電話を見て、どの患者かを確かめます。
  3. 「診察券番号で結びつける」の欄に 診察券番号（①）を入れ、結びつける（②）を押します。
  4. いたずらなどで不要な回答は「削除」（管理操作のできる人）。

院長・管理者は「問診票を患者の基本情報へ写し直す」で、結びついている問診票の内容を患者の空いている欄へまとめて写し直せます（手で直した欄は変えません。先に控えを取ります）。

10. カルテ・同意書・見積

どれも、予約の詳細パネルのボタン、または患者画面から開きます。

10-1. カルテ（施術の記録）

  1. 詳細パネルの 🩺 カルテ を押します。
  2. 施術名（予約のメニューが入っています）、＋部位・＋条件・＋薬剤・＋麻酔、所見・経過、次回の予定、施術者を入れます。
  3. 保存 を押します。上の「重要事項…を書く」で注意事項を、「既往歴・内服歴」で問診票の内容を確認できます。下でその日の写真・ファイルも追加できます。

10-2. 同意書

  1. 詳細パネルの 📄 同意書 を押します。その予約のメニューに結びついた同意書が先頭に出ます。上の欄で探すこともできます。
  2. 同意書を押すと、患者名と日付が入った本文が出ます。「施術」の欄も確かめます。
  3. どちらかを選びます。 - ✍ この端末で署名する：枠の中に指またはペンで署名してもらい、署名して保存（「書き直す」でやり直し）。 - 🖨 署名せず印刷（紙に署名）：紙に印刷して署名してもらう。
  4. 保存すると控えが患者画面の「同意書」に残ります。🖨 印刷・PDF で印刷・PDFにできます。

同意書のひな形が1つもないときは「同意書のひな形がまだありません」と出ます（設定 → 同意書／取り込み で用意します）。写真の同意書は、マニュアル用に作った架空のひな形です。

未確認 Googleドライブから最新の文面を読み込む仕組み（読み込み元の設定）は、デモでは設定していません。

10-3. 見積・会計

  1. 詳細パネルの 📝 見積/会計 を押します。右上で 御見積書／御会計書 を切り替えます（端末ごとに前回の選択を覚えます）。
  2. 「この予約のメニューに合う料金」や「料金表」「スキンケア＆内服」の一覧から項目を押して追加します。「さがす」で探せます。
  3. 単価・数量を直します。「＋自由入力の行」「＋割引（掛け率）」「＋割引（金額）」も使えます。合計（税込）と消費税が自動で出ます。
  4. 発行日・有効期限・備考を確かめ、御見積書を作る（会計書なら御会計書を作る）を押します。
  5. 保存されると番号（例：No.2026-0001）が付き、印刷できます。

患者画面の下の「同意書」「見積・会計」に控えの一覧があり、印刷・直す・削除（管理操作のできる人）ができます。

11. 1日の流れ（朝・診療中・終業）

朝（診療前）

  1. 自分の名前でログインします（2章）。
  2. 「今日」を押して今日の予約表を開き、「全体表示」で1日をざっと見ます。
  3. 予約枠の 「!」（注意事項） と 赤い三角（重なり） を確かめます。重なりは必要なら動かします。
  4. Todaysメモ に担当スタッフ・機器の点検など、その日の注意を書きます。
  5. 受付の画面が患者から見える場所なら「氏名を伏せる」を押します。

診療中

  1. 患者が来たら、受付一覧または詳細パネルで 来院済 にします。
  2. 待ち・診察中・処置中・会計待ちと進むたびに状態を変えます。急ぎの一言は「＋自由入力」。
  3. 施術の内容は 🩺 カルテ、写真は 📷 撮影、同意書は 📄 同意書 で残します。
  4. 会計時は 📝 見積/会計 で会計書を作り、終わったら 帰宅 にします。
  5. 次回の予約は、予約表の空いている所を押して入れます（日付のカレンダーの「4週後」などが便利です）。
  6. 電話でのキャンセルは キャンセル、来なかった人は 無断キャンセル にします（必ず「はい」の確認が出ます）。
  7. ほかの端末で変えた内容は20秒ごとに反映されます。すぐ見たいときはページを開き直します。

終業

  1. 今日の予約が全部「帰宅」かキャンセル系になっているか、受付一覧で確かめます。
  2. 翌日の予約表を開き、注意事項・重なりを確かめます。
  3. 共用の端末では「名前 ⇄」でログアウトします。
  4. バックアップ・リマインドは院のサーバーの設定で動きます。大きな変更をした日は、院長・管理者が 設定 →「控え・復元」の 「今すぐ控えを取る」 で控えを取っておくと安心です（13章）。

リマインド

予約のお知らせ（リマインド）とAirリザーブの取り込みの設定は、「リマインド」 のタブにまとめています（以前は「院の情報・診療時間」にありました）。左が「リマインド（予約のお知らせ）」、右が「Airリザーブの取り込み」、その下が「リマインドで見せるメニュー」です。

  • リマインド（予約のお知らせ）（院長・管理者）：LINE・メールで予約のお知らせを送る設定です。
  • 状態：「止めている」／「自動で送る」。「自動で送る」を押すと「自動送信を始めます。…よろしいですか？」と確認が出ます。横に、最後に確認した日時と cron（サーバーの自動実行）の最終実行が出ます。
  • 送る回：最大3回。何日前（当日・前日・○日前）と時刻（6:00〜21:00）。決めた時刻から3時間のあいだに送ります。当日の回は30分より先の来院だけ、当日に取った予約には送りません。
  • LINE で送る／メールで送る、LINE の残しておく通数、送信元のメール、送信元の名前（空欄＝院名）、返信先のメール（空欄＝送信元）。来院ごとに1通、LINE がつながっている人には LINE、ほかはメールで送ります（患者ごとの「リマインドの送り先」「リマインド不要」が優先）。LINE の残り通数が「残しておく通数」以下になったとき、また送っている途中で LINE の送信上限に達したときは、その回の残りの人には LINE を試さずメールで送ります（メールがない人には送りません）。
  • 文面：{患者名} {院名} {いつ} {日付} {時刻} {メニュー} {来院前のご案内} {院の電話} を入れられます。「標準の文面に戻す」「保存する」。
  • LINE の鍵：Messaging API チャネルの「チャネルアクセストークン（長期）」を入れます。保存すると画面には二度と表示しません。
  • 今すぐ確認して送る：決めた時刻を過ぎていれば、まだ送っていない来院へ送ります（同じ来院・同じ回には二度送りません）。予約の詳細の「今すぐ送る」で1件だけ送ることもできます（6-1）。
  • Airリザーブの取り込み（院長・管理者）：毎朝、決めた時刻（5:00〜16:59）を過ぎたら翌日分の予約をAirリザーブから取り込む設定です（状態「止めている／毎朝取り込む」、取り込む時刻、Air のログイン ID・パスワード、取り込む日を選んで今すぐ取り込む）。ログイン情報は暗号化して保存し、画面には二度と出しません（入れるまでは「毎朝取り込む」と「今すぐ取り込む」は押せません）。Air予約番号で同じ予約を探して時刻・レーン・メニューをAirに合わせ、Airで取り消された・消えた予約は取り消しにします。リマインドを送る20分前にも、その回の対象日をもう一度取り込みます。既存の患者に結びついた予約で、患者のメールアドレスが空のときは Air のメールアドレスで補います（入っているメールは変えません）。既存の患者と結びつけられず新しく登録した患者は 「要確認」 の一覧に出て、予約の詳細の名前の横にも赤い「要確認」が出ます。同じ人がいれば患者画面で統合し、別の人なら一覧の「確認済み」を押します。
  • Air と見比べる（読むだけ）（院長・管理者）：期間（一度に62日まで、過去の日も可）を選んで「見比べる」を押すと、Airの予約とLANE RESERVEの予約（Air予約番号つき）を見比べ、違う人・時刻やレーンのずれ・片方にしかない予約・同じ予約番号の二重を一覧にします。何も書き換えません。
  • リマインドで見せるメニュー（管理操作のできる人）：メニューごとに 「患者に見せる名前」（リマインドの {メニュー} に入る。空欄ならメニュー名。院内の略称【再診】などを患者に見せないため）と 「来院前の案内」（本文の最後、または {来院前のご案内} の場所に入る。1回の来院に複数のメニューがあるときはまとめて1回だけ）を入れ、行ごとに「保存」を押します。「まだ入れていないものだけ」で絞り込めます。メニューの編集画面でも同じ欄を直せます。
  • 予約申請のLINEを患者に紐付ける：予約申請IDのLINEが見つかり、名前・生年月日が患者と合うとき、詳細パネルの申請IDの横に「LINE（申込者）」と「＋患者に紐付け」が出ます（4-4）。家族が代わりに申し込んだ場合は紐付けないでください。

未確認 実際に LINE・メールでリマインドを送る操作（「自動で送る」「今すぐ確認して送る」「今すぐ送る」）と、Airリザーブにログインする操作（「今すぐ取り込む」「見比べる」、要確認の一覧・見比べの結果）は、デモでは試していません。写真の送信元のメールは架空のアドレスで、自動送信は「止めている」のままです。

送り先の確認（送りません）

「リマインド（予約のお知らせ）」のいちばん下にあります。LINE・メールは送りません。 前日のうちに、送り先が足りない患者を見つけるのに使います（院長・管理者）。

  1. 日付（①、最初は明日）を選び、「確かめる」（②）を押します。
  2. 「LINE ○件・メール ○件・送れない ○件」（③）と、その日の来院ごとの表（④）が出ます。LINE の鍵が入っているときは、LINE の今月の残り通数も出ます。 - 時刻・患者：来院の時刻と患者（押すと患者画面）。同じ日の枠が複数あっても、来院ごとに1行です。キャンセル・承認待ちの予約は出ません。 - 送り先：「LINE」「メール」「送れない」。送り先の選び方は実際の送信と同じです。 - LINE：LINE がつながっていれば「あり」（予約申請IDの申込者の LINE か、患者に紐付けた LINE）。 - メール：メールアドレスの一部を伏せて出します（例：sa***@example.com）。 - 届かない・使わない理由：「LINE のつながりなし」「LINE の鍵が入っていない」「LINE の残り通数が少ない」「申請IDの LINE が見つからない」「申請の名前・生年月日が患者と合わない」「メールアドレスなし」「メールアドレスの形が正しくない」「送信元のメールが未設定」「LINE（メール）で送る設定が『送らない』」「リマインド不要の患者」など。
  3. 「送れない」の患者は、患者画面の連絡先情報でメールアドレスや「リマインドの送り先」を確かめるか、LINE を紐付けます（4-4）。

この写真は、画面の幅を狭くして（横1000px）撮っています。広い画面では左の列に出るので、表が横にはみ出すときは表を横にずらして見ます。写真では LINE の鍵を入れていないため、LINE がつながっている人も「LINE の鍵が入っていない」でメールか送れないになっています。

データの控えを取る

  1. 予約表の ⚙ →「控え・復元」のタブを開きます。
  2. 「今すぐ控えを取る」（①）を押します。
  3. 「いまのデータの控えを作ります。少し時間がかかることがあります。よろしいですか？」と出るので OK を押します。
  4. 「控えを作りました（○MB・確認 ok）」と出て、カードの下に作った日時・ファイル名・大きさが出ます。

設定の復元

14. 困ったとき（FAQ）

Q. 保存できない／「保存できませんでした」と出る - 画面の下に赤い知らせが出たら、その文を読んでください。通信が切れていないか確かめ、ページを開き直してからもう一度行います。 - 予約の登録では、患者・メニューを選んでいない、診療時間を超えている、などの理由が赤字で出ます（4-2）。 - 設定の変更で「この操作の権限がありません」と出たら、管理操作のできる人に頼んでください（15章）。

Q. 「他の端末で先に更新されました」と出た（同時に編集した） - ほかの人が同じ予約・患者・記録を先に変えています。上書きはされません。予約表は自動で最新に読み直されます。患者画面では「最新の内容を読み込む」を押し、もう一度直してください（8-9）。

Q. ログインできない／「5分間ログインできません」と出た - PINを5回続けて間違えたためのロックです。表示された時間を待ってから入れ直してください。続けて間違えると、ロックの時間が長くなります。 - PINを忘れたときは、院長・管理者に設定 → スタッフ →「PINを変更」で新しいPINにしてもらいます。 - 「利用停止」になっていると名前が出ません。院長に確認してください。 - 院の入口のパスワード（Basic認証）を聞かれて分からないときは院長に聞いてください。

Q. 急にログイン画面に戻った - ログインは12時間で切れます。また、PINの変更・役割の変更・利用停止があると、その人のログインは切れます。

Q. 予約枠を押しても動かない・ずれる - スマホ・タブレットでは長押ししてから動かします。動かしたあと「はい」を押すまでは保存されません。

Q. 空いている所を押しても予約画面が出ない - 詳細パネルが開いているときは、1回目の押しで詳細が閉じます。もう一度押してください。診療時間の外は押しても開きません。

Q. キャンセルした予約が見えない - 「キャンセル表示」を押すと薄く表示されます。

Q. 間違えてキャンセル（無断キャンセル）にしてしまった - 「キャンセル表示」を押し、その予約の枠を押して詳細を開き、「予約に戻す」 →確認で OK を押します（7-3）。入れ直す必要はありません。

Q. バックアップ（控え）を取りたい - 院長・管理者が 設定 →「控え・復元」の 「今すぐ控えを取る」 を押します（13章）。取り込み・統合などの大きな変更の前に押しておくと安心です。院長・管理者以外のログインでは、このタブは出ません。

Q. リマインドが届かない患者がいる - 予約の詳細の「リマインド」に、送れなかった理由が出ます（6-1）。 - 院長・管理者は、設定 →「リマインド」の 送り先の確認（送りません） で、日付を選んで「確かめる」を押すと、来院ごとの送り先と届かない理由を前もって確かめられます（13章）。 - 「送れない」の患者は、患者画面の連絡先情報にメールアドレスを入れるか、LINE予約申請の LINE を紐付けます（4-4）。

Q. 予約表の時刻の範囲を変えたい - 設定 → 院の情報・診療時間 で開院・閉院時間を変えます（管理操作のできる人）。時間外の予約も表示はされます。

Q. 使い方がわからない - 予約表の ⚙（設定）→ いちばん右の 「操作マニュアル」 のタブで、このマニュアルを読めます（13章）。スタッフ全員が開けます。上の検索欄で語句を探せます。

Q. 文字が小さい - 上のバーの「文字」で、標準→大きめ→特大と切り替わります（この端末だけ）。

15. 役割ごとにできること

16. 開発者向けメモ

  • コードの場所：apps/reserve/。画面は Next.js で src/app/（page.tsx＝予約表、login/、patients/、patients/view/、settings/、consents/print/、estimates/print/）、部品は src/components/（calendar/ 予約表・詳細・登録、patients/、settings/、consents/、estimates/、charts/、questionnaires/）。裏側（API・保存・業務ルール・ログインと権限）は PHP で php/ にあります（以前あった Node.js 版の裏側は削除済み）。
  • APIの入口：本番では /reserve/api/v1（例：/reserve/api/v1/day?date=YYYY-MM-DD）。開発では npm run dev（scripts/dev.sh）で PHP の API（php -S）と画面（next dev）をいっしょに起動し、/api/v1 で使います。開発のデータは .data/php/（設定 config.php・データ reserve.db・写真などの blobs/・PHP のログ php.log）で、初回にデモデータを入れます。作り直すときはこのフォルダを消します。
  • 名前とロゴ：サービス名は LANE RESERVE（レーンリザーブ）。ロゴ・アイコンは public/brand/（ログイン画面は lane-reserve-logo.svg、上のバーは英字だけの lane-reserve-logo-wordmark.svg で横1280px以上のときだけ表示）、ホーム画面用は public/manifest.webmanifest、タブの題名は src/app/layout.tsx（「○○｜LANE RESERVE」）。
  • 操作マニュアル：設定の「操作マニュアル」のタブは public/manual/index.html を埋め込んで表示します（部品は src/components/settings/ManualTab.tsx）。このフォルダの内容を取り込み直すときは scripts/update-manual.sh を使います。
  • 控え：「今すぐ控えを取る」は POST /api/v1/admin/backup（{"confirm":"BACKUP"}、院長・管理者のみ）。写真などのファイルは data/blobs/ に保存されます。サーバーでの控えと復元の手順は php/README.md を見てください。
  • 受付箱：GET /api/v1/intake・POST /api/v1/intake/{申請ID}/mark。申請は、LINE の受け口（line-webhook）が保存した intake-records/R{受付日時（UTC）14桁}{16進の大文字8桁}.json を読むだけです（場所は設定の line_intake_dir、開発では .data/php/intake-records/）。中身は type: "reservation_intake"・requestId・receivedAt・intake（visitType・preferredDate・name・kana・phone・birthDate など）・message.text・source.userId。申込者の LINE の ID は画面に出さず、リマインドの送り先選びと「＋患者に紐付け」（POST /api/v1/reservations/{id}/link-line）でだけ使います。
  • リマインド：設定は GET/PUT /api/v1/admin/reminders、送り先の確認（送らない）は GET /api/v1/admin/reminders/preview?date=YYYY-MM-DD、今すぐ確認して送るは POST /api/v1/admin/reminders/run、予約1件へ今すぐ送るは POST /api/v1/reservations/{id}/remind（いずれも本当に送るのは run と remind だけ）。自動送信は cron（php/cron/reminders.php）から動きます。
  • 同時編集：予約・患者などは version を持ち、古い版での保存は「他の端末で先に更新されました」で止まります（409）。
  • デモ：架空の患者・予約は php/tools/demo-seed.php で入れます。デモのPINは全員 1234。
  • 運用のルール：予約・患者などの運用データは院の運用ルールの対象です。患者の情報（氏名・電話・カルテ内容など）を、ログ・チャット・課題管理・AIへの指示文に書かないでください。 調べるときは架空のデモデータを使い、本番のデータや本番の画面・APIには触れないでください。
  • このマニュアルの写真のうち、予約表・カルテ・同意書・見積・スマホ・受付箱・リマインド・Airリザーブの設定の写真は、PHP 版に一本化した開発版（npm run dev、デモデータ）で撮影しました。患者画面と、リマインド・Air 以外の設定の写真は、それより前の開発版のままです。受付箱の申請は intake-records/ に置いた架空の申請ファイルです。リマインドの実際の送信と、Airリザーブへのログイン（取り込み・見比べ）は試していません。
