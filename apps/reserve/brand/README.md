# LANE RESERVE（レーンリザーブ）ロゴ

院長が採用した Canva のデザイン（`canva-original.png`）を、アプリで使えるデータに作り直したものです。
文字はすべて図形（パス）にしてあるので、端末のフォントによって形が変わりません。

- 英字：Marcellus
- カタカナ：Shippori Mincho SemiBold

どちらも SIL Open Font License のフォントです。

## ファイル

| ファイル | 使う場所 |
| --- | --- |
| `lane-reserve-logo.svg` / `-dark.svg` | 縦組みのロゴ（マーク・LANE RESERVE・レーンリザーブ）。ログイン画面、マニュアルの表紙など |
| `lane-reserve-logo-horizontal.svg` / `-dark.svg` | 横組みのロゴ。画面上部のバーなど、高さが限られる場所 |
| `lane-reserve-icon.svg`（明るい地）/ `lane-reserve-icon-navy.svg`（紺の地） | アプリのアイコン・ファビコン |
| `icon-512.png` / `icon-192.png` / `apple-touch-icon.png`（180px）/ `favicon-32.png` | ホーム画面に追加したときのアイコン、ブラウザのタブ |
| `preview.html` / `preview.png` | 見本 |

## 色

| 名前 | 値 | 用途 |
| --- | --- | --- |
| 紺 | `#0d1b2e` | 英字・マークの線 |
| 金 | `#92845b` | カタカナ・マークの中央の線 |
| 白の地 | `#f5f2ea` | アイコンの地、濃い背景での文字 |
| 金（濃い背景用） | `#b9a77a` | 濃い背景でのカタカナ・中央の線 |

マークは、予約台帳の「レーン」を表す5本の縦線です。中央の1本だけ金色にしています。
