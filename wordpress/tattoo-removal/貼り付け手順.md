# タトゥー除去ページ 貼り付け手順（パターン2：ダーク・レーザーラボ）

## 使うファイル

| ファイル | 貼る場所 |
|---|---|
| `wordpress-paste.html` | 治療メニュー（service）新規追加 → 本文の「テキスト」タブ |
| `custom.css` | 外観 → カスタマイズ → 追加CSS |
| `images/` の7点 | メディア → 新規追加 |
| `seo.md` | タイトル・スラッグ・メタディスクリプションの値 |

## 手順

1. **画像をアップロード**（メディア → 新規追加）
   `tattoo-pico-device.webp`、`tattoo-case1〜3-before.jpg`、`tattoo-case1〜3-after.jpg` の7点を、ファイル名を変えずにアップロードします。
   2026年10月中にアップロードすれば、URLは `https://ishidahihuka.jp/wp-content/uploads/2026/10/ファイル名` になり、HTMLのまま表示されます。
   月をまたいだ場合は、`wordpress-paste.html` 内の `/2026/10/` を、実際のURLの年月に置き換えてください。

2. **治療メニューを新規追加**
   - タイトル：`seo.md` の「投稿タイトル」
   - スラッグ：`tattoo-removal`
   - カテゴリー・アイキャッチ：`seo.md` 参照
   - 本文：エディタを **「テキスト」タブ** に切り替えて、`wordpress-paste.html` の中身を全部貼り付けます。
     **ビジュアルタブには切り替えないでください**（タグが消えたり崩れたりします）。

3. **追加CSSを貼る**（外観 → カスタマイズ → 追加CSS）
   - 以前貼ったタトゥー除去用のCSS（`.tt-guide` で始まるもの）があれば、すべて削除します。
   - `custom.css` の中身を貼ります。先頭の `@import` 行は **追加CSSのいちばん上** に置いてください（途中にあると無効になります。本文側にもフォント読み込みを入れてあるので、表示は崩れません）。

4. **下書きのままプレビュー**して、PCとスマホ（iPhoneのSafariを含む）で確認します。

5. 問題なければ公開し、`seo.md` の「公開後にやること」を進めます。

## 確認ポイント

- 皮膚断面図の光線、症例写真、料金カードが表示されているか
- 本文末尾の構造化データ（`<script type="application/ld+json">`）が保存後も残っているか（テキストタブで確認）
- スマホ下部の固定LINEバナーは、テーマ側の既存要素です

## 確認済みのこと

- 実際の治療ページ（テーマ：TCD NOEL）の本文枠に差し込み、PC・スマホとも崩れず表示されることを確認しました。
- WordPressの自動整形（wpautop）を通したあとも、レイアウトが崩れないことを確認しました。
