# 商標登録願 下書き（LANE RESERVE）

> **最終確認は弁護士・弁理士・司法書士にお願いします。** 願書の様式と指定商品・役務の書き方は、提出前に特許庁の最新の案内（「商標登録出願の手引き」「類似商品・役務審査基準」）で必ず確かめてください。
> 作成：2026-10-15。根拠：商標法 第5条・第6条、商標法施行規則 様式第2、特許法等関係手数料令（出願料 3,400円＋8,600円×区分数）。
> **提出（出願料の支払い）はユーザーの承認を得てから行います。** 【 】は記入する箇所です。

## 1. 出し方の選択
| 方法 | 必要なもの | 費用（2区分） | 向いている場合 |
|---|---|---|---|
| **紙で出す（おすすめ）** | 願書（A4・下の様式）、**特許印紙**（収入印紙ではない。郵便局などで買える）20,600円分 | 出願料 20,600円 ＋ 紙を電子データにする手数料（あとで別に請求が来る。数千円程度【金額は要確認】） | 1件だけ出すとき。準備が簡単 |
| ネットで出す | 特許庁の「インターネット出願ソフト」、会社の電子証明書（法務局が出す「商業登記電子証明書」）、パソコンの設定 | 出願料 20,600円 ＋ 電子証明書の手数料 | 今後もたびたび出すとき |

- 紙の場合の提出先：特許庁の窓口（東京都千代田区霞が関3-4-3）か、郵送（特許庁長官 宛。**簡易書留など記録の残る方法**で、封筒に「商標登録願在中」と書く）。
- 出願日は、郵送なら**発送した日**（郵便局の受付日）になります。

## 2. 願書の本文（紙・標準文字の場合）

A4の白い紙を縦に使い、横書きで書きます。左右と上下に余白（2cm程度）をとり、**特許印紙は左上の余白**に貼ります（消印はしない）。

```
（20,600円）

【書類名】　　　　　　　商標登録願
【整理番号】　　　　　　LR-TM-001
【提出日】　　　　　　　令和8年【 】月【 】日
【あて先】　　　　　　　特許庁長官　殿
【商標登録を受けようとする商標】
【標準文字】
　　　　　　　　　　　　LANE RESERVE
【指定商品又は指定役務並びに商品及び役務の区分】
　【第9類】
　　【指定商品（指定役務）】電子計算機用プログラム
　【第42類】
　　【指定商品（指定役務）】電子計算機用プログラムの提供，電子計算機のプログラムの設計・作成又は保守，予約管理用電子計算機用プログラムの提供
【商標登録出願人】
　【識別番号】　　　　　【（初めての場合は書かない）】
　【住所又は居所】　　　東京都豊島区【登記どおりに】
　【氏名又は名称】　　　株式会社エアフォルティアコンサルティング
　【代表者】　　　　　　【代表取締役の氏名】
　【電話番号】　　　　　【 】
```

### 書き方の注意
- 「【標準文字】」と書くと、特許庁が決めた文字の形で登録されます。ロゴや字体は守られませんが、文字そのものを広く守れます。
- 英字だけで出しても、読み方「レーンリザーブ」も審査で考慮されるのが通常です。カタカナの「レーンリザーブ」を別に出すかは、予算に余裕ができたら考えます（出すと費用がもう一組かかります）。
- 指定商品・役務は、審査基準に載っている言い方に合わせています。
  - 第9類「電子計算機用プログラム」（類似群コード 11C01）
  - 第42類「電子計算機用プログラムの提供」（42X11）、「電子計算機のプログラムの設計・作成又は保守」（42P02）
  - 「予約管理用電子計算機用プログラムの提供」は、何をするサービスかをはっきりさせるための追加です。書き方を直すように言われたら、削っても構いません。
- 1つの区分に多くの商品を書きすぎると、「本当に使うのか」を確かめる書類を求められることがあります。今の数なら問題ないと考えられます。
- 会社名と住所は、**登記と一字一句同じ**に書きます。
- 代表者の印は、紙の願書では原則として不要です【最新の様式で要確認】。

## 3. 出したあとの流れ
| 時期 | 起きること | やること |
|---|---|---|
| 出願から数週間 | 特許庁から「識別番号」（出願人の番号）の通知や、紙の場合は電子化手数料の払込用紙が届く | 手数料を払う。識別番号を記録する |
| 出願から数か月〜1年程度 | 審査の結果が届く | 問題がなければ「登録査定」。問題があれば「拒絶理由通知」（意見を出す期間は通常40日） |
| 登録査定から30日以内 | 登録料を払う | 2区分で 65,800円（10年分）か、34,400円（5年分）。**払わないと登録されない** |
| 登録 | 商標権が生まれる（10年） | 更新の時期をカレンダーに入れる |

- 拒絶理由通知が来たら、その時点で弁理士に相談するのがおすすめです（「リザーブ」の部分を指摘される可能性があります）。
- いしだ皮フ科で「LANE RESERVE」の名前を実際に使っているなら、**早期審査**（審査を早めてもらう申し出）ができる場合があります。使っていることがわかる資料（画面の写しなど）が要ります。条件は特許庁の「商標早期審査・早期審理ガイドライン」で確かめてください。
