## 2. 先行調査の進め方（J-PlatPat：特許庁の無料の検索サービス）

1. J-PlatPat（https://www.j-platpat.inpit.go.jp/）を開き、「商標」→「商標検索」を選びます。
2. **読み方（称呼）で探します。** 次の読みで、それぞれ検索します。
   - 「レーンリザーブ」（全体）
   - 「レーン」「リザーブ」（一部分）。一部が同じだと似ていると判断されることがあるためです。
   - 似た音：「レインリザーブ」「レーンリザーヴ」「ラインリザーブ」
3. **類似群コード（似た商品・サービスをまとめた番号）で絞ります。**
   - 第9類 ソフトウェア：`11C01`
   - 第42類 プログラムの提供（クラウドで使わせるサービス）：`42X11`
   - 第42類 プログラムの設計・作成・保守：`42P02`
   - コードは「類似商品・役務審査基準」で確かめてください。審査基準は改訂されます。
4. 見つかった商標ごとに、①読み・見た目・意味が似ているか、②区分とコードが重なるか、③権利が生きているか（存続中か）を表にします。
5. 「Airリザーブ」など「〜リザーブ」で終わる予約サービスの商標が多くあると考えられます。「リザーブ」は「予約」の意味を表す言葉で、それだけでは他社と見分ける力が弱いため、**「LANE」の部分で区別できるか**が判断の中心になります。ここは弁理士に見てもらう価値が高い点です。

## 3. 区分の案

| 区分 | 内容（指定する商品・サービスの例） | 入れるか |
|---|---|---|
| 第9類 | 電子計算機用プログラム、ダウンロード可能なコンピュータソフトウェア（予約管理用） | ◎ |
| 第42類 | 電子計算機用プログラムの提供、予約管理用ソフトウェアの提供（SaaS）、電子計算機のプログラムの設計・作成・保守 | ◎（いちばん大事） |
| 第35類 | 顧客情報の管理、事務処理の代行など | △：受付代行などの事務サービスを始めるときに検討 |
| 第44類 | 医業、美容、エステティック など | ×（今は不要） |

### 3-1. 第42類がいちばん大事な理由
LANE RESERVE は、院がインターネット越しに使うサービス（SaaS）として提供するためです（apps/reserve/docs/saas-plan.md 第1章）。

### 3-2. 第9類を入れる理由
アプリやソフトを渡す形（スマホアプリなど）になったときに備えるためです。42類と一緒に出すのが一般的です。

### 3-3. 第44類を入れない理由
第44類は「医療・美容のサービスそのもの」の区分です。LANE RESERVE は医療を行う側ではなく、院に道具を提供する側なので、44類で守る意味は小さいと考えられます。院が「LANE RESERVE」という名前で施術を行うことは想定していません。

## 4. 費用の目安と、自分で出すか弁理士に頼むか

### 4-1. 特許庁に払うお金（印紙代）
| 項目 | 計算 | 2区分のとき |
|---|---|---|
| 出願料 | 3,400円 ＋ 8,600円 × 区分数 | 20,600円 |
| 登録料（10年分を一括で払う場合） | 32,900円 × 区分数 | 65,800円 |
| 登録料（5年ずつ分けて払う場合） | 17,200円 × 区分数 × 2回 | 34,400円 × 2回 |
| **合計（10年分一括）** | | **約86,400円** |

- 根拠：特許庁「産業財産権関係料金一覧」と、令和4年（2022年）4月1日の料金改定（登録料は 28,200円 から 32,900円 に、分けて払う場合は 16,400円 から 17,200円 に変わりました）。2025年版の特許庁年次報告書でも同じ金額です。
- 英字とカタカナを別々に出すと、上の金額が2倍になります。

### 4-2. 比べると
| | 自分で出す | 弁理士に頼む |
|---|---|---|
| 費用 | 印紙代だけ（2区分で約8.6万円） | 印紙代 ＋ 手数料の目安 7〜15万円（調査・出願・登録の合計。事務所によって大きく違います） |
| 手間 | 電子出願ソフトの準備、または書面での出願 | ほぼ任せられます |
| 却下の通知（拒絶理由通知）への対応 | 自分で意見書を書きます。難しめです | 任せられます（別料金になることが多い） |
| 向いている場合 | 調査で似た商標がほぼ見つからないとき | 「〜リザーブ」の商標と似ていると判断されるおそれがあるとき |

**おすすめ：** 「リザーブ」で終わる予約サービスの商標が多いと考えられるため、最初の調査と出願は弁理士に頼むほうが安全です。弁理士の手数料は見積もりを2社ほど取って比べてください。

### 4-3. 期間
- 出願から最初の審査の結果まで、通常で数か月〜1年程度かかります。
- 実際に使っている、または使う準備をしている商標は「早期審査」を申し込めることがあります。条件は特許庁の「商標早期審査・早期審理ガイドライン」で確かめてください。

## 5. 会社の登記で確かめること

### 5-1. やること
1. 登記の内容を書いた書類（履歴事項全部証明書）を取ります。法務局の窓口か、オンライン（登記・供託オンライン申請システム）で数百円です。
2. 書類の「目的」の欄に、次のような内容が入っているかを確かめます。

| 確かめる内容 | 文言の例 |
|---|---|
| ソフトウェアの開発・販売 | 「コンピュータソフトウェアの企画、開発、販売、保守及び運用」 |
| インターネットで提供するサービス | 「インターネット等の通信ネットワークを利用した情報処理サービス及び情報提供サービス」 |
| 附帯業務 | 「前各号に附帯又は関連する一切の事業」 |

- 「経営コンサルティング」だけで、ソフトウェアやインターネットのサービスが入っていない場合は、目的を追加する変更を検討します。附帯業務の文言で読めるかどうかは、司法書士に確かめてください。
- 目的に入っていないと、銀行口座・審査・取引先の与信審査などで、事業の内容と合わないと見られることがあります。

### 5-2. 目的を変えるときの流れと費用
1. 株主総会で定款の変更を決めます。普通の決議より条件の厳しい「特別決議」が必要です（会社法 第466条・第309条第2項第11号）。
2. 変更してから**2週間以内**に、本店のある場所で変更の登記をします（会社法 第915条第1項）。
3. 費用：登録免許税 30,000円（登録免許税法 別表第一 第24号(1)ツ）。司法書士に頼む場合は、別に報酬が 2〜5万円ほどかかるのが目安です。

### 5-3. あわせて確かめること
- 商標の出願人の名前・住所を、登記と同じ書き方にします。
- 院向けの販売で、特別な許可や届け出が必要かどうかは compliance-gap.md でまとめます（例：電気通信事業の届け出が必要かどうか）。
