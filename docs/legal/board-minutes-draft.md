## 議案　予約管理システム「LANE RESERVE」の利用に関する契約の承認の件

議長から、次の取引について理事会の承認を求めたい旨の提案があった。

### 1. 取引の内容
| 項目 | 内容 |
|---|---|
| 相手方 | 株式会社エアフォルティアコンサルティング（以下「同社」という。） |
| 取引の種類 | 同社が提供する予約管理システム「LANE RESERVE」の利用契約（利用規約、個人情報の取扱いに関する覚書）、開発協力に関する覚書 |
| 料金 | 【無償】（開発協力の対価として、同社が当法人に無償で利用させる） |
| 期間 | 【令和8年○月○日から1年間。自動更新】 |
| 当法人が負う主な義務 | 運用上の意見・不具合の報告を同社に提供すること。患者の個人情報は同社に委託する範囲でのみ扱わせること |

### 2. 重要な事実の開示
理事長【氏名】から、次の事実が開示された。
1. 理事長は、同社の発行済株式のすべてを保有している。
2. 理事長は、同社の役員・従業員ではない。同社の代表取締役は【氏名】である。
3. 「LANE RESERVE」は同社が開発し、開発の費用は同社が負担している。
4. 当法人は、本取引について同社に料金を支払わない。

### 3. 審議
議長から、次の説明があった。
- 当法人は、本取引により、予約管理と患者情報の管理のシステムを無償で利用できる。
- 患者の個人情報は、同社への委託として取り扱い、同社が自らの目的に利用しないことを覚書で定める。
- 同社が他の医療機関への販売のために、当法人の運用上の知識を利用する場合も、患者の情報と、当法人を特定できる情報は利用させない。
- 本取引は当法人に不利益となるものではなく、非営利性に反しないと考えられる。

なお、理事長【氏名】は特別の利害関係を有するため、本議案の審議・議決に加わらなかった。
