# 医療広告・薬機法と、外部サービスの規約の注意点

> **最終確認は弁護士・弁理士・司法書士にお願いします。** このメモは注意点の下書きで、個別の文面が適法かを判断するものではありません。
> 作成：2026-10-10。根拠：医療法 第6条の5〜第6条の7、厚生労働省「医業若しくは歯科医業又は病院若しくは診療所に関する広告等に関する指針」（医療広告ガイドライン。2026年3月30日付 医政発0330第4号で一部改正。2024年3月22日付で限定解除の要件を見直し）、医薬品医療機器等法（薬機法）第66条〜第68条、不当景品類及び不当表示防止法（景表法）第5条とステルスマーケティングの告示（2023年10月施行）、特定電子メールの送信の適正化等に関する法律（特定電子メール法）。

## 1. 前提：LANE RESERVE と広告の関係
- 院が LANE RESERVE に入れた**メニュー名・説明・料金**が、患者の見る画面（LINE の予約画面、Web の予約画面など）に出る場合、それは院の「広告」と扱われることがあります。医療広告ガイドラインは、Web サイトや SNS も対象にしています。
- 広告かどうかは、①患者を受診に誘う意図があるか（誘引性）、②院の名前がわかるか（特定性）で判断されます。
- **予約済みの患者に送る日時の確認だけのリマインドは、通常は広告にあたらない**と考えられます。ただし、リマインドに「キャンペーン」「おすすめ施術」などを添えると広告になります。
- 文面の責任は院にあります（利用規約 第6条第3項）。当社は、間違いやすい点を画面で注意する、ひな形を用意する、という支援にとどめます。

## 2. リマインドの文面
| してよい | 避ける | 理由 |
|---|---|---|
| 予約の日時、院の名前、持ち物、キャンセルの連絡先 | 病名、薬の名前、施術の詳しい内容（例：「○○の注射」「ニキビ治療」） | 画面をのぞかれたり端末を共有したりすると、受診の内容が知られてしまうためです（個人情報の保護） |
| 「ご予約の確認です」 | 「今なら20%オフ」「次回はこちらもおすすめ」 | 広告になります。広告として送るなら、医療広告の決まりを全部守る必要があります |
| 案内だけの送信 | 予約していない人にまとめて送る宣伝 | LINE は院の公式アカウントの友だちに限る。メールで宣伝を送る場合は、特定電子メール法で事前の同意と表示（送り主・配信停止の方法）が必要です |

**提案（アプリの改修案）**：リマインドのひな形に、上の「避ける」言葉（割引・キャンペーン・薬の名前など）が入ったら注意を出す機能。

## 3. メニュー名・説明（患者の見る画面に出る場合）
| 禁止・注意 | 例 | 根拠 |
|---|---|---|
| うそ・大げさ | 「必ず消える」「痛みゼロ」「最高の」「日本一」 | 医療法 第6条の5第2項（虚偽・比較優良・誇大の禁止） |
| ほかの院と比べてすぐれていると言う | 「他院より安い」「No.1」 | 同上 |
| 体験談 | 「患者さまの声」「口コミ」 | 医療広告ガイドライン（治療の内容・効果についての体験談は禁止） |
| 治療前後の写真（ビフォーアフター） | 説明なしの写真 | 治療の内容、費用、リスク・副作用などの説明を一緒に載せないと不可 |
| 費用を強調 | 「今だけ半額」「モニター価格」を大きく | 医療広告ガイドライン（費用を強調して誘う表示） |
| **自由診療（保険が使えない診療）** | 美容の施術全般 | 「限定解除」の条件（問い合わせ先、治療の内容、標準的な費用、期間・回数、主なリスク・副作用）を満たす場合だけ、詳しく書けます |
| **未承認の医薬品・医療機器** | 海外から医師が個人輸入した薬・化粧品・注射など | 薬機法 第68条（承認前の医薬品などの広告の禁止）。院の Web などに載せるときは、医療広告ガイドラインの限定解除の条件として、**未承認であること、入手の経路、国内に同じ成分の承認品があるか、海外での安全性の情報、副作用が起きたときの救済制度の対象外であること**を書く必要があります |
| 医薬品の名前を使った誘い | 「○○（商品名）注射キャンペーン」 | 医療用医薬品は一般の人への広告が制限されています（薬機法 第66条・第67条、医薬品等適正広告基準） |
| 口コミを頼んで書いてもらう | 「口コミを書いたら割引」 | 景表法のステルスマーケティングの規制（2023年10月から）。広告であることを隠した表示は禁止 |

**いしだ皮フ科で特に確かめたい点**：個人輸入で取り寄せている薬（例：ドライブ上の個人輸入依頼書にある製品）をメニュー名に入れて、患者の見る画面に出していないか。出すなら限定解除の説明を一緒に出すか、院内向けのメニュー名と患者向けの表示名を分けます。

**提案（アプリの改修案）**：
- メニューに「院内向けの名前」と「患者向けの表示名」を分けて持たせる。
- 患者向けの表示名に、未承認の製品名や「必ず」「No.1」などが入ったら注意を出す。
- メニューに「自由診療」「未承認の製品を使う」の印をつけ、患者向けの画面では限定解除の説明文へのリンクを必ず出す。

## 4. 外部サービスの規約上の注意点
各社の規約は変わるので、契約・連携の前に最新版を読んでください。【要確認】は、この環境で本文を確かめられなかった点です。

### 4-1. LINE 公式アカウント・Messaging API（LINE ヤフー株式会社）
- **契約者は院です。** LINE の開発者向けの管理画面（プロバイダー）も院の名義にし、当社は院から任されて設定・運用する形にします。当社名義のプロバイダーで複数の院のアカウントをまとめると、院をまたいで同じ人を見分けられる形になり、委託の範囲を超えるおそれがあります。
- LINE の利用者ID（患者ごとの番号）は個人情報として扱い、院の外に出さない。
- 医療機関のアカウントは、LINE 公式アカウントの審査ガイドラインで業種ごとの制限があります。【要確認：医療機関・自由診療の配信の制限】
- 友だち追加の時点で、リマインドや案内を送ることの説明を表示する。
- 送信の数に応じて料金がかかる（プランによって無料の通数が違う）。リマインドの通数が院の料金に影響します。

### 4-2. Airリザーブ（株式会社リクルート）
- **予約の取り込み方を確かめる必要があります。** 公式の書き出し機能（CSV など）や公式の連携の仕組みを使うのは問題になりにくいです。一方、**画面を自動で操作して読み取る方法（RPA・スクレイピング）は、規約で禁止されていることが多く、アカウントの停止などのおそれがあります。**【要確認：Airリザーブ 利用規約の禁止事項】
- Airリザーブから持ち出したデータも院の患者の個人情報です。LANE RESERVE に取り込んだあとの扱いは委託契約によります。

### 4-3. Google フォーム（Google LLC）
- **いまの院の Google アカウントは無料の個人向け（gmail.com）と見られます。** 個人向けのアカウントは、会社が使う前提の契約（Google Workspace）と比べて、データの取扱いについての約束（データ処理の条項など）が弱いです。病歴などを含む問診票を扱うには向いていないと考えられます。
- 選ぶ道：①Google Workspace（有料の業務用）に切り替えて、データ処理の条項に同意する、②**国内にデータを置く問診票のサービスに切り替える**（おすすめ。患者への説明が簡単になります。privacy-draft.md 第2部3）。
- 外国にある第三者への提供のルール（個情法 第28条）が関係します（compliance-gap.md 1章）。

### 4-4. ネオボワール（撮影機器）
- 機器メーカーとの契約・規約で、写真を機器の外に取り出して別のシステムに保存することが認められているか。【要確認】
- 機器メーカーが遠隔保守で写真を見られる設定になっていないか（なっていれば、メーカーも院の委託先になります）。

### 4-5. M3（電子カルテ）
- カルテ番号の照らし合わせなど、電子カルテとのつながりは、電子カルテの会社の規約・院との契約で認められている方法で行う。【要確認】

## 5. ユーザー・院長に決めていただきたいこと
- [ ] 患者の見る画面に出しているメニュー名に、未承認の製品名や誇大な言葉がないかの点検（院で実施。必要なら当社のチェック機能で支援）
- [ ] Airリザーブからの取り込みの方法（公式の書き出し機能に寄せるか）
- [ ] 問診票を Google Workspace にするか、国内のサービスに切り替えるか
- [ ] LINE の管理画面（プロバイダー）が院の名義になっているかの確認
