# 個人情報の取扱いに関する覚書（委託契約）下書き

> **最終確認は弁護士・弁理士・司法書士にお願いします。** これは話し合いのたたき台です。そのまま締結しないでください。
> 作成：2026-10-10。根拠：個人情報の保護に関する法律（以下「個情法」）第23条〜第28条、同施行規則 第7条・第8条、厚生労働省「医療情報システムの安全管理に関するガイドライン 第6.0版」、経済産業省・総務省「医療情報を取り扱う情報システム・サービスの提供事業者における安全管理ガイドライン 第2.0版」（以下「提供事業者GL」）。

（院の名称）（以下「甲」という。）と株式会社エアフォルティアコンサルティング（以下「乙」という。）は、甲が乙に提供を受ける予約管理サービス「LANE RESERVE」（以下「本サービス」という。）の利用規約（以下「本規約」という。）に基づき、甲が乙に取扱いを委託する個人情報について、次のとおり覚書（以下「本覚書」という。）を締結する。

## 第1条（目的と優先関係）
1. 本覚書は、甲が乙に委託する個人情報の取扱いについて、個情法その他の法令およびガイドラインに沿った安全管理を確保することを目的とする。
2. 本覚書と本規約の内容が異なるときは、個人情報の取扱いについては本覚書を優先する。

## 第2条（定義）
1. 「委託個人情報」とは、甲が本サービスに入力し、または甲の指示により本サービスが外部から取り込む、甲の患者および従業者に関する個人情報（要配慮個人情報を含む。）をいう。
2. 「医療情報」とは、委託個人情報のうち、病歴、施術歴、診療記録の補助メモ、写真、同意書、問診票その他、厚生労働省のガイドラインがいう医療情報にあたるものをいう。

※院が「情報の持ち主（管理の責任者）」、乙が「取扱いを任された側」という整理です（個情法 第27条第5項第1号）。

## 第3条（委託の内容）
1. 甲は乙に対し、次の業務（以下「委託業務」という。）のために必要な範囲で委託個人情報の取扱いを委託する。
   1. 本サービスの提供（予約・患者情報・施術記録・写真・同意書の保存、表示、検索）
   2. 甲の指示による外部サービスからの取り込みと、外部サービスへの送信（予約の取り込み、問診票の取り込み、リマインドの送信など）
   3. バックアップ、障害対応、保守
   4. 甲から求められたデータの書き出し、返還、削除
2. 委託する個人情報の項目、本人の範囲、保存場所は、別紙1のとおりとする。

## 第4条（目的外利用の禁止）
1. 乙は、委託個人情報を委託業務の目的以外に利用してはならない。
2. 乙は、委託個人情報を、他の医療機関のデータと合わせて分析すること、乙の営業や宣伝に使うこと、および人工知能その他の機械学習の学習データとして使うことをしない。
3. 乙が本サービスの改善のために利用状況を集計するときは、個人を識別できない統計情報（院の識別もできないもの）に限る。

※第2項・第3項を守ることが、委託として扱われるための前提です（個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン」に関する Q&A）。

## 第5条（安全管理措置）
1. 乙は、委託個人情報の漏えい、滅失または毀損を防ぐため、提供事業者GLに沿って、別紙2の安全管理措置を講じる。
2. 乙は、委託個人情報を日本国内に設置されたサーバーに保存し、【日本国内でのみ】取り扱う。保存場所を変えるときは、事前に甲に書面（電子的な方法を含む。以下同じ。）で通知する。
3. 乙は、提供事業者GLに基づく「サービス仕様適合開示書」を甲に交付し、内容に大きな変更があったときは更新して交付する。

## 第6条（従業者の監督）
1. 乙は、委託個人情報を取り扱う従業者を必要最小限とし、守秘義務を課し、教育を行う（個情法 第24条）。
2. 乙の従業者は、障害対応その他やむを得ない場合を除き、医療情報を閲覧しない。閲覧するときは、事前に甲の許可を得て、閲覧の記録を残す。ただし緊急の場合は、閲覧後速やかに甲に報告する。

## 第7条（再委託）
1. 乙は、別紙3に記載した再委託先（サーバー、保存、バックアップの事業者）を除き、甲の事前の書面による承諾なく、委託業務を第三者に再委託しない。
2. 乙は、別紙3の再委託先を追加または変更するときは、【30日】前までに甲に通知する。甲は、合理的な理由があるときは異議を述べることができる。
3. 乙は、再委託先に本覚書と同等の義務を負わせ、監督する。再委託先の行為については、乙が甲に対して責任を負う。
4. 甲が自ら契約する外部サービス（LINE 公式アカウント、Airリザーブ、Google フォーム、撮影機器など）は、乙の再委託先ではない。乙は、甲の指示と設定に従ってこれらと情報をやりとりする。

※LINE・Air・Google の契約者は院です。院がそれぞれの規約に沿って使っているかは院が確かめる、という整理です（compliance-gap.md 4章）。

## 第8条（事故が起きたとき）
1. 乙は、委託個人情報の漏えい、滅失、毀損、またはそのおそれ（以下「事故」という。）を知ったときは、**【24時間】以内**に甲に第一報を入れ、次の事項を、わかった範囲で順次報告する。
   1. 起きた事柄と、知った日時
   2. 対象となる本人の数と、情報の項目（要配慮個人情報が含まれるか）
   3. 原因
   4. 二次被害の有無とそのおそれ
   5. 本人への対応
   6. 再発防止策
2. 乙は、甲が個人情報保護委員会への報告（速報・確報）と本人への通知（個情法 第26条、施行規則 第7条・第8条）を行えるよう協力する。
3. 乙は、甲の同意なく、事故について本人または報道機関に公表しない。ただし、法令で求められる場合はこの限りではない。

※要配慮個人情報は、1件でも漏えいのおそれがあれば報告の対象です（施行規則 第7条第1号）。院の報告の期限は、速報が「知ってから速やかに」（目安3〜5日）、確報が30日以内（不正な目的のおそれがある場合は60日以内）です（施行規則 第8条）。

## 第9条（監査への協力）
1. 甲は、乙の安全管理の状況について、年1回、書面での報告を求めることができる。
2. 事故が起きたときその他合理的な理由があるときは、甲は、事前に通知したうえで、乙の業務時間内に、委託業務に関係する範囲で確認を行うことができる。費用の分担は別に協議する。
3. 乙は、第三者による脆弱性診断（セキュリティの弱点の検査）その他の点検の結果の要約を、甲の求めに応じて開示する。

## 第10条（返還と削除）
1. 契約が終わるとき、甲は、終了日から【60日】以内に、乙が定める形式（CSV、PDF、画像ファイルなど）で委託個人情報の書き出しを受けることができる。
2. 乙は、前項の期間が過ぎたあと【30日】以内に、本サービスから委託個人情報を復元できない方法で削除する。バックアップに残る委託個人情報は、バックアップの保存期間（【最長90日】）が終わったときに削除されるものとする。
3. 乙は、削除が終わったら、削除証明書を甲に交付する。
4. 甲が法令で保存を求められている記録（診療に関する記録など）の保存は、甲の責任で行う。

## 第11条（本人からの求め）
本人から甲に、開示・訂正・利用停止などの求めがあったときは、乙は、本サービスの機能または合理的な範囲での作業により、甲の対応に協力する。

## 第12条（損害賠償）
本覚書に違反して甲に損害を与えたときの乙の責任は、本規約の定めによる。ただし、乙の故意または重大な過失による場合は、本規約の責任の上限は適用しない。

## 第13条（有効期間）
本覚書は、本規約に基づく利用契約の期間中有効とする。第4条、第6条第1項、第8条、第10条、および第12条は、契約の終了後も、委託個人情報の削除が終わるまで（守秘義務は終了後【5年間】）効力を持つ。

## 別紙2 安全管理措置（現状と予定）
| 区分 | 内容 | 状況 |
|---|---|---|
| 暗号化 | 保存データを1件ずつ暗号化（AES-256-GCM）。通信は HTTPS | 実施中 |
| 暗号鍵の管理 | 鍵をデータと別の場所で管理 | 【予定】（compliance-gap.md A2） |
| 認証 | 入口の認証、スタッフごとのログイン、連続失敗でロック | 実施中 |
| 二要素認証 | パスキー・端末の登録 | 【予定】（compliance-gap.md A5） |
| 権限 | 役割ごとに操作を制限 | 実施中 |
| 記録 | 操作ログ・閲覧の記録を【5年】保存 | 一部実施（保存期間は未設定） |
| バックアップ | 毎日、別の場所へ暗号化したまま保存。年1回以上の復元の練習 | 【予定】（compliance-gap.md A6） |
| 脆弱性診断 | 外部の診断を年1回と大きな変更のあと | 【予定】（compliance-gap.md B8） |
| 運営側の閲覧 | 原則として閲覧しない。閲覧したら記録 | 【予定】（compliance-gap.md B9） |

※「予定」が残ったまま締結すると、約束を守れないおそれがあります。販売前に「実施中」にしてから使ってください。
